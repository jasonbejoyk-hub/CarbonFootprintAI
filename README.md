Project Overview
CarbonFootprintAI is a Python-based data science project that analyzes historical carbon dioxide (CO₂) emissions data using real-world datasets. The goal is to explore emissions trends, apply machine learning techniques, and develop an interactive policy simulation that demonstrates how emission reduction strategies could influence future outcomes.
The project follows a complete data science workflow, including data loading, data cleaning, exploratory data analysis (EDA), visualization, and future predictive modeling using regression.
Current Features
Load real-world CO₂ emissions datasets using Pandas.
Verify dataset integrity by checking file paths and data availability.
Clean and prepare data for analysis.
Detect missing values and duplicate records.
Create cleaned DataFrames for machine learning.
Visualize historical emissions trends using Matplotlib.
Track development using Git and GitHub.
